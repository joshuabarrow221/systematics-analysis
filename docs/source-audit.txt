5. Baseline/L over E: explicit geometry, not recovered truth
----------------------------------------------------------
SRTrueInteraction.baseline is metres; actual stored values must be divided by
1000 for km. Inspected CAFMaker leaves baseline/prod_vtx unfilled (lines468-469).
Parent's independent 2000-event primitive probe found all2000 baseline values
NaN. Thus an honest actual-baseline true L/E is unavailable in this probe.
Explicit true_baseline_mode=geometric uses true angle and a fixed-height shell;
reco L/E always uses reconstructed angle with the same geometry and reco E.
  r=R-depth; L=sqrt(r*r*cosZ*cosZ+(R+h)^2-r*r)-r*cosZ
  defaults R6371km, h15km, depth0km. cosZ+1 down-going gives h+depth;
  cosZ-1 up-going gives2R+h-depth. Divide L[km] by E[GeV].
The 15 km height is the user's latest slide-based choice for this analysis,
overriding the earlier 25 km assumption. R6371/h25 appear in the inspected
MaCh3 atmospheric covariance config, while current NuOsc uses production-height
distribution averaging. The source's historical 25 km value is not being
misidentified as the newly selected 15 km convention. This fixed-height visualization
is NOT equivalent to that averaging, and depth0 is an explicit convention,
not a sourced SURF detector depth. All parameters are configurable.

7. Required inputs and interface
--------------------------------
Required branch constants and the raw cache schema are defined in
atmospheric_response/v2_extract.py. Pure observable functions and their units
are in atmospheric_response/v2_physics.py. Semantic physics regression tests
are in tests/test_v2_physics.py; extraction and resume integrity tests are in
tests/test_v2_extract.py. Run these from the repository root with:
  python -m pytest tests/test_v2_physics.py tests/test_v2_extract.py
These tests use small arrays and local byte files, without ROOT ingestion.
The module returns every input row with separate observable masks. It never
globally removes an event for invalid direction, energy decomposition, FC/PC,
or missing baseline. The caller applies selected category/containment/binning.

9. Electron reconstructed-y endpoint in the first-file diagnostic
----------------------------------------------------------------
With the current common selection, the first file has 48247 valid CC reco-y
values; none equals1 or lies within1e-5 of1. Of384 electron/antielectron events
in 0.99<=y<=1,381 have Erec-Ehad within1keV of0.511MeV. This is an observed
electron-rest-mass signature, not an artificial calo/calo=1 assignment.
The inspected producer computes p=sqrt(T*(T+2*m_e)), E_lep=sqrt(p*p+m_e*m_e),
then adds hadronic energy to obtain total energy. Thus T near0 gives
y near1-m_e/Erec. Zero reconstructed electron kinetic energy is a strong
inference for these events; the exact production build and individual shower
associations were not established from this local cache check.
